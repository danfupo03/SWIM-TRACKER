# Swim Tracker

A small web app to log your swim times and see personal bests, stats and history per test and season.

Built with [Bun](https://bun.com), [Elysia](https://elysiajs.com), SQLite (`bun:sqlite`), [HTMX](https://htmx.org) and [DaisyUI](https://daisyui.com) on Tailwind CSS.

## Prerequisites

- **Bun** (v1.4 or newer)
  - Windows (PowerShell):
    ```powershell
    powershell -c "irm bun.sh/install.ps1 | iex"
    ```
  - macOS / Linux:
    ```bash
    curl -fsSL https://bun.sh/install | bash
    ```
  - Restart your terminal afterwards and check it works with `bun --version`.
- **Git**: [git-scm.com/downloads](https://git-scm.com/downloads)

## Setup

```bash
git clone https://github.com/danfupo03/SWIM-TRACKER.git
cd SWIM-TRACKER
bun install
bun run start
```

Then open http://localhost:3000. Press `Ctrl+C` to stop.

`bun run start` builds the CSS and starts the server in one terminal, and both reload when you edit files.

### About the database

The SQLite database (`swim-tracker.db`) is **not** in the repo. It is created automatically in the project root the first time the server starts, so you begin with an empty tracker. To reset everything, stop the server and delete that file.

## Project structure

The code uses a Model–Service–Controller (MSC) layout, grouped by feature:

```
src/
├── index.tsx              # Entry point: creates the Elysia app, mounts modules and pages
├── db/
│   └── database.ts        # Opens the SQLite database and creates tables
├── modules/
│   ├── time/              # Logging, editing and deleting swim times
│   │   ├── time.model.ts       # Validation schemas and types
│   │   ├── time.service.ts     # Database queries
│   │   ├── time.controller.tsx # HTTP routes (/times)
│   │   └── time.views.tsx      # HTML fragments returned to HTMX
│   └── stats/             # Summary, personal bests and chart data
│       └── stats.{model,service,controller,views}
└── views/
    ├── layout.tsx         # Shared HTML shell
    ├── dashboard.tsx      # "/" page
    ├── history.tsx        # "/history" page
    └── components/        # Nav, icons, page header
public/
├── js/dashboard.js        # Client-side script for the dashboard
└── output.css             # Generated by Tailwind (git-ignored, do not edit)
app.css                    # Tailwind + DaisyUI source styles and theme
```

## Scripts

| Command             | What it does                                                               |
| ------------------- | -------------------------------------------------------------------------- |
| `bun run start`     | Runs `build:css` and `dev` together in one terminal. Use this normally.     |
| `bun run dev`       | Starts only the server on port 3000, restarting on file changes.          |
| `bun run build:css` | Only compiles `app.css` into `public/output.css` and watches for changes.  |

If you run `dev` and `build:css` separately, use two terminals. The page has no styles until `build:css` has run at least once.
